# 🍳 CookBuddy

CookBuddy is a recipe discovery and management web application that helps users explore recipes, view recipe details, and save their favorite recipes.

## 🚀 Features

* 🔐 User Registration and Login
* 🔎 Search and explore recipes
* 🍽️ View detailed recipe information
* ❤️ Add and remove favorite recipes
* 👤 User profile management
* 📱 Responsive user interface
* 🌐 Recipe data powered by the Forkify API

## 🛠️ Technologies Used

### Frontend

* React.js
* JavaScript
* CSS
* Tailwind CSS

### Backend

* Python
* Flask
* REST API

### Database

* PostgreSQL

## ▶️ Running Locally

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
cd server
pip install -r requirements.txt
python app.py
```

## 🌐 Deployment

The application is designed to be deployed using Render:

* React frontend → Render Static Site
* Flask backend → Render Web Service
* PostgreSQL → Render PostgreSQL
